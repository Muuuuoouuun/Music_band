# 그랜드 피아노 샘플

**Salamander Grand Piano V3** — Alexander Holm, [CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/)
(원본: <https://archive.org/details/SalamanderGrandPianoV3>, SFZ 판: <https://github.com/sfzinstruments/SalamanderGrandPiano>)

음색 공방에서 쓰려고 원본을 이렇게 바꿨습니다.

- A0 부터 단3도 간격 30개 음 × 세기 3층(원본 16층 중 4·9·14번)만 골랐습니다.
- 낮은 음은 7초, 높은 음은 2.5초 안팎으로 자르고 끝을 0.45초 동안 줄였습니다.
- 44.1 kHz 스테레오 MP3(112 kbps)로 바꿨습니다.

파일 이름은 `{음}v{원본 층}.mp3` 이고, `#` 은 `s` 로 썼습니다 (`Ds4v9.mp3` = D#4, 9층).
