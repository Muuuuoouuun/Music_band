# 음색 공방 (Soundsmith)

브라우저에서 바로 소리가 나는 **가상악기 작업실**입니다. 고급 신스 음색을 만들고 다듬고, **음원 파일이나 유튜브 링크의 소리를 듣고 닮은 음색을 만들고**, 녹음한 소리를 가공해 샘플 악기로 쓰고, 박에 맞춰 겹쳐 쌓고, 튜닝을 바꿔 볼 수 있습니다. 무엇을 왜 이렇게 만들었는지는 [음색 앱 조사](../../docs/SYNTH_APP_RESEARCH.md)를 따릅니다.

## 실행하기

```bash
cd apps/soundsmith
npm start            # python3 server.py → http://127.0.0.1:8010
```

npm 패키지 설치가 필요 없습니다. 외부 라이브러리·워클릿 없이 브라우저 기본 Web Audio 노드만 씁니다. `npm start` 는 앱 파일과 함께 **링크 가져오기 도우미**(`server.py`, 파이썬 표준 라이브러리)를 엽니다.

| 링크 종류 | 필요한 것 |
|---|---|
| 음원 파일 링크 (`.mp3`·`.wav`·`.m4a` …) | [ffmpeg](https://ffmpeg.org) |
| 유튜브 등 영상 사이트 | ffmpeg + `pip install yt-dlp` (deno·node 가 있으면 함께 씀) |
| 봇 확인을 요구하는 영상 | `python3 server.py --cookies-from-browser chrome` |

도우미 없이 `npm run static`(정적 서버)이나 claude.ai 미리보기로 열면 링크 가져오기만 빠지고 파일 불러오기·예시 소리는 그대로 됩니다. 도우미는 이 컴퓨터(127.0.0.1)에서만 열리고, 다른 사이트의 페이지가 몰래 받기 요청을 못 하도록 Origin·Host 를 확인합니다. 받은 구간은 `.cache/links` 에 하루 동안 둡니다.

## 화면

| 화면 | 할 수 있는 것 |
|---|---|
| **음색 만들기** `#synth` | 기본 음색 **45개**(패드·건반·현악·합창·관악·벨·베이스·리드·줄·텍스처, 크기를 같은 세기로 맞춤). 도우미 슬라이더 4개(밝기·따뜻함·공간·움직임)와 **섞기**(지금 음색 → 고른 음색으로 서서히, 둘 사이에서 새 음색). 파형 14종(현악·금관·리드·모음·유리·틴 건반·**직접 그림**), **배음 그리기**(128배음 막대를 끌어서), FM·숨소리, 줄 뜯기 물리 모델, **12/24dB 필터**, 엔벨로프, LFO, **어택 소리(해머·숨)·아날로그 흔들림·세기 반응**, 드라이브·**로파이·페이저·컴프**·코러스, **딜레이 3방식(가운데·핑퐁·테이프)·딜레이 밝기**, **잔향 6종류(룸·홀·교회·플레이트·스프링·앰비언트)·고역 감쇠**·프리딜레이·잔향 밝기·쉬머·스테레오 폭, **EQ 3밴드와 맞춤 EQ 10띠**(실제 응답 곡선). **들어 보기**: 건반 없이 한 음·화음·아르페지오·끊어 치기로 시험 연주, **이펙트 끄고 듣기(A/B)**, 잔향 패널의 **꼬리 재기**(짧은 소리를 넣어 잰 꼬리 그림과 RT60·시작·크기·좌우 넓이·딜레이 반복). 랜덤 9종류, 변주, 되돌리기, 내 음색 저장, JSON 내보내기·불러오기 |
| **음원 따라 만들기** `#match` | 음원 파일·**유튜브/음원 링크**(시작·길이만큼만 받음)·예시 소리·샘플러 소리를 불러와 구간을 고르면(추천 구간 3개, 끌기·숫자) 소리를 잽니다. 그다음 **① 닮은 음색 만들기** **② 지금 음색에 톤만 입히기** **③ 구간을 샘플로** **④ 앰비언트 패드로 늘리기**. 닮은 정도(%)와 항목별 점수, 원음 구간 ↔ 만든 음색을 같은 크기로 번갈아 듣기, **더 비슷하게** |
| **샘플러 · 루프 지점** `#sampler` | 오디오 파일·마이크 녹음·데모 소리·지금 음색 굽기. 무음 자르기 → 음높이 찾기(YIN) → 루프 지점 찾기 자동. 파형에서 시작·끝·루프 표시 끌기, 이음새 그림과 매끄러움 %, 크로스페이드, 한 번만·반복·왕복. **가공: 거꾸로·늘리기(×2·×4·×8)·앞뒤 페이드·지금 음색의 이펙트 입히기·원래대로**, WAV 저장(이펙트를 입혔으면 스테레오). SFZ 악기(.sfz + .wav) zip 내보내기 |
| **루퍼** `#looper` | 4트랙, 트랙마다 다른 음색. 카운트 후 녹음·겹쳐 쌓기·마지막 바퀴 실행 취소, BPM·박자·마디·퀀타이즈·메트로놈·뮤트·솔로·볼륨 |
| **튜닝** `#tuning` | 기준음 A4, 조옮김, 미세 조정, 옥타브 늘이기, 음률 6가지와 기준 조, 음마다 cent, 주파수 표, 평균율 ↔ 이 튜닝 번갈아 듣기, 마이크 튜너, Scala(.scl) |

아래 건반은 늘 붙어 있습니다. 화면 건반(위쪽 = 여리게), 컴퓨터 키보드(`A W S E D F T G Y H U J K` = C4부터, `Z`/`X` 옥타브), Web MIDI(서스테인 CC64), `홀드`.

## 음원 따라 만들기는 이렇게 합니다

고른 구간(최대 12초)을 재서 종류를 먼저 정합니다.

| 종류 | 언제 | ① 닮은 음색 만들기가 하는 일 |
|---|---|---|
| **한 음** | 악기 하나가 한 음을 낼 때 (전주의 패드 한 음, 끝 음, 악기 시연 영상) | 배음 128개의 세기를 재서 **파형을 직접 그리고**, 어택·서스테인·릴리즈, 첫소리 밝기(필터 엔벨로프), 비브라토·트레몰로, 숨소리(배음 사이 바닥), 늘어난 배음(피아노 줄 → FM), 첫소리 잡음(어택 소리), 좌우 폭, 꼬리의 잔향을 옮깁니다 |
| **화음·지속음** | 여러 음이 함께 울릴 때 | 값으로 본 가장 닮은 기본 음색 셋을 실제로 연주해 견주고, 가장 닮은 것에서 출발해 공간·폭·어택을 옮깁니다 |
| **여러 소리 섞임** | 밴드 전체가 나오는 곳 | 같은 방법으로 성격을 맞추고 **톤 균형**에 집중합니다. 악기 하나로 똑같이 만들 수는 없어서, 소리 그대로가 필요하면 ③·④ 를 쓰세요 |

만든 음색은 **같은 음·같은 길이로 미리 연주(OfflineAudioContext)해서 원음과 같은 자로 다시 잽니다.** 꼬리 크기·줄어드는 속도 차이로 잔향을 고치고, 옥타브 10띠의 톤 균형 차이를 **맞춤 EQ** 로 메웁니다. `더 비슷하게`는 차단 주파수·어택·디케이·숨소리·폭·잔향 등을 하나씩 위아래로 움직여 닮은 정도가 오르는 쪽만 받아들입니다.

**닮은 정도**는 톤 균형·배음·엔벨로프·밝기·폭·공간을 견준 점수입니다. 같은 엔진으로 만든 소리(기본 음색을 듣고 그 음색을 빼고 만들기)는 77~95% 가 나옵니다. 실제 녹음, 특히 여러 악기가 섞인 곡은 점수가 낮고 귀로 들어 판단해야 합니다.

- **② 톤만 입히기**: 지금 음색은 그대로 두고 원음의 톤 균형(맞춤 EQ)·공간·폭만 입힙니다. 좋아하는 기본 음색을 그 곡 느낌으로 바꿀 때.
- **③ 구간을 샘플로**: 구간을 그대로 샘플러에 걸어 건반으로 칩니다 (루프 자동).
- **④ 앰비언트 패드로 늘리기**: Paulstretch(창마다 위상을 흩어 늘리기)로 4~16배 늘려 흐르는 패드를 만들고, 길게 크로스페이드한 루프로 겁니다. 곡의 화음 느낌이 그대로 남는 워십 패드가 됩니다.

## 이펙트 설정과 시험

잔향·딜레이는 값만 바꾸는 게 아니라 **바로 들어 보고 숫자로 확인**할 수 있습니다.

| 하는 일 | 어디서 | 무엇을 알 수 있나 |
|---|---|---|
| 시험 연주 | 음색 만들기 맨 위 `들어 보기` | 건반 없이 한 음·화음·아르페지오·끊어 치기(잔향 꼬리 듣기). 베이스는 낮은 음, 모노 음색은 한 음씩 |
| A/B | `이펙트 끄고 듣기` | 저장된 음색은 그대로 두고 드라이브~잔향·EQ·폭을 잠깐 빼서 이펙트가 하는 일을 견줌 |
| 꼬리 재기 | `잔향 · 공간` 패널의 그림 | 5ms 짧은 소리를 이펙트 줄에 넣고, 같은 줄에서 딜레이·잔향만 뺀 소리를 빼서 젖은 소리만 잽니다. 꼬리 길이(RT60, 슈뢰더 적분), 시작 시간(프리딜레이+방 종류), 직접음 대비 크기, 좌우 넓이, 딜레이 반복 간격·좌우 번갈아. 값을 바꾸면 다시 잽니다 |
| 내 소리에 걸기 | 샘플러 `가공` → `지금 음색의 이펙트 입히기` | 녹음·불러온 소리에 지금 음색의 이펙트를 꼬리까지 구워 넣고, 원래대로 되돌리거나 스테레오 WAV 로 저장 |

잔향 종류는 같은 길이라도 첫 반사·밀도·밝기가 다릅니다: 룸(가까운 첫 반사가 빽빽), 홀(고르고 부드럽게, 예전 잔향과 같음), 교회(천천히 차오르고 어둡게), 플레이트(반사 없이 바로 빽빽하고 밝게), 스프링(일정한 간격의 띠잉), 앰비언트(천천히 부풀며 출렁임). 고역 감쇠는 꼬리가 갈수록 어두워지는 정도(벽이 소리를 먹는 정도)입니다.

## 소리 구조

```text
음 하나: 오실레이터 ×겹치기(아날로그 흔들림·위상 흩기) (+FM·노이즈) | 줄 뜯기 | 샘플
         ─ 필터 12/24dB (엔벨로프·LFO·세기) ─ 트레몰로 ─ 볼륨 엔벨로프
         + 어택 소리(해머·숨) + 옥타브 위 복사본 → 쉬머(잔향으로만)
악기:   음들 ─ 드라이브 ─ 로파이 ─ 페이저 ─ 코러스 ─┬─ 그대로 ──────────────┐
                                                  ├─ 딜레이(BPM 에 맞춤, 가운데·핑퐁·테이프) ──┤
                                                  └─ 프리딜레이 ─ 잔향(6종류) ────────────────┴─ EQ 3밴드 ─ 맞춤 EQ ─ 컴프 ─ 스테레오 폭 ─ 볼륨
스튜디오: 악기들 ─ 리미터 ─ 마스터 ─ 오실로스코프 ─ 스피커
```

- 줄 뜯기는 band2sheet `sound.py` 의 Karplus-Strong 을, 잔향 임펄스는 AirChoir `audio.js` 방식을, 따뜻한 파형 배음은 두 앱의 합성기를 옮겼습니다. 앱끼리 코드를 직접 불러오지는 않습니다.
- 모든 악기가 `freq(midi)` 하나로 음높이를 얻어서 튜닝을 바꾸면 신스·줄·샘플·루퍼 트랙이 다음 음부터 함께 바뀝니다.
- 같은 `Instrument` 를 `OfflineAudioContext` 에 만들면 '음색 굽기'·'음원 따라 만들기'의 비교 렌더·'꼬리 재기'·'이펙트 입히기'가 됩니다. 아날로그 흔들림도 시드가 있는 난수라 같은 음색은 늘 같은 소리로 렌더됩니다.
- 미리 연주는 한 번에 하나씩 차례로 돌립니다. 크롬에서 잔향이 있는 렌더 둘이 동시에 돌면 꼬리가 잘리거나 딜레이가 비는 일이 있어(꼬리 재기 검사에서 발견) 줄을 세웠습니다. 같은 잔향 임펄스는 한 번만 만들어 나눠 씁니다.

## 저장되는 것

- 이 브라우저에만: 내 음색(`soundsmith.presets.v1`), 마지막 음색(`soundsmith.patch.v1`), 튜닝(`soundsmith.tuning.v1`). 음색 형식은 2판이고 1판 음색·파일도 그대로 불러집니다(새 값은 담백한 기본값).
- 샘플·루퍼 녹음·불러온 음원은 **페이지 메모리에만** 있습니다. 남길 샘플은 SFZ zip 으로 내보내세요.
- 링크 도우미가 받은 구간: `.cache/links` (하루 뒤 지움). 그 밖의 서버 전송은 없습니다.

브라우저 검사는 이미 설치된 Playwright·Chromium 을 씁니다(새로 받지 않음). 자동 검사는 소리가 나는지·숫자가 깨지지 않는지·주파수와 닮은 정도가 기준을 넘는지까지 확인하며, 실제로 듣기 좋은지는 사람이 들어 봐야 합니다.

## 한계

- 여러 악기가 섞인 곡에서 악기 하나만 골라 내지는 않습니다(음원 분리 없음). 악기가 혼자 나오는 구간을 고르거나 ③·④ 를 쓰세요. band2sheet 의 음원 분리로 뽑은 악기 트랙을 불러오면 '한 음' 방식이 됩니다.
- 다시 합성한 파형은 잰 음높이의 배음 모양을 다른 음에도 그대로 씁니다(웨이브테이블 방식). 원음에서 멀리 떨어진 음은 실제 악기와 달라질 수 있습니다.
- 샘플러는 한 소리를 건반 전체에 늘려 씁니다(멀티 샘플·벨로시티 레이어 없음).
- 유튜브는 사이트 정책에 따라 막힐 수 있습니다(데이터센터 주소의 403, 봇 확인). 이럴 때는 yt-dlp 를 최신으로 올리거나 `--cookies-from-browser` 를 쓰고, 그래도 안 되면 음원 파일을 받아 불러오세요.
- 탭이 뒤로 가면 브라우저가 타이머를 늦춰 루퍼 박이 흔들릴 수 있습니다. claude.ai 미리보기에서는 마이크·MIDI·링크가 막혀 있습니다.
- 플러그인(VST3·CLAP·AU)은 아직 없습니다. 같은 구조를 C++ 로 옮기는 계획은 조사 문서 5단계에 있습니다.
