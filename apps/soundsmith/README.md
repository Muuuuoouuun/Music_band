# 음색 공방 (Soundsmith)

브라우저에서 바로 소리가 나는 **가상악기 작업실**입니다. 고급 신스 음색을 만들고 다듬고, **음원 파일이나 유튜브 링크의 소리를 듣고 닮은 음색을 만들고**, 녹음한 소리를 가공해 샘플 악기로 쓰고, 박에 맞춰 겹쳐 쌓고, 튜닝을 바꿔 볼 수 있습니다. 무엇을 왜 이렇게 만들었는지는 [음색 앱 조사](../../docs/SYNTH_APP_RESEARCH.md)를 따릅니다.

## 실행하기

```bash
cd apps/soundsmith
npm start            # python3 server.py → http://127.0.0.1:8010
```

npm 패키지 설치가 필요 없습니다. 외부 라이브러리·워클릿 없이 브라우저 기본 Web Audio 노드만 씁니다. `npm start` 는 앱 파일과 함께 **링크 가져오기 도우미**(`server.py`, 파이썬 표준 라이브러리)를 엽니다.

| 링크 종류 | 필요한 것 |
|---|---|
| 음원 파일 링크 (`.mp3`·`.wav`·`.m4a` …) | [ffmpeg](https://ffmpeg.org) |
| 유튜브 등 영상 사이트 | ffmpeg + `pip install yt-dlp` (deno·node 가 있으면 함께 씀) |
| 봇 확인을 요구하는 영상 | `python3 server.py --cookies-from-browser chrome` |

도우미 없이 `npm run static`(정적 서버)이나 claude.ai 미리보기로 열면 링크 가져오기만 빠지고 파일 불러오기·예시 소리는 그대로 됩니다. 도우미는 이 컴퓨터(127.0.0.1)에서만 열리고, 다른 사이트의 페이지가 몰래 받기 요청을 못 하도록 Origin·Host 를 확인합니다. 받은 구간은 `.cache/links` 에 하루 동안 둡니다.

## 처음 쓰는 법

1. 오른쪽 위 **소리 켜기** (브라우저는 한 번 눌러야 소리를 냅니다).
2. **음색 만들기**의 서랍에서 음색을 고릅니다. 휴대폰에서는 분류 칩(패드·건반·국악기…)을 먼저 고릅니다.
3. 아래 건반, 컴퓨터 자판(`A S D F…`, 검은 건반 `W E T Y U`, `Z`/`X` 옥타브), USB·블루투스 MIDI 건반으로 칩니다.
4. 도우미 슬라이더와 **고민별 다듬기**로 맞추고 **내 음색으로 저장**.

처음 열면 음색 만들기 위에 이 네 단계가 카드로 나오고(닫으면 다시 안 나옴), 머리의 **사용법** 단추나 `?` 키로 언제든 안내 창(처음 3분 · 화면마다 · 음색 다듬는 법 · 음높이 맞추기 · 실제 연주에서 · 단축키)을 엽니다. 음색 만들기는 처음에 **간단히** 보기(들어 보기·필터·볼륨 엔벨로프·잔향·연주 볼륨)로 열리고, **모두**로 바꾸면 오실레이터·LFO·이펙트·EQ 패널까지 나옵니다. 고른 보기는 기억합니다.

## 음색 다듬는 법

1. **비슷한 음색에서 출발**: 서랍, 음원 따라 만들기, 랜덤 만들기.
2. **들어 보기**로 한 음·화음·아르페지오·끊어 치기를 들으며 고칩니다.
3. **도우미**(밝기·따뜻함·공간·움직임)로 큰 방향을 정합니다. 가운데가 지금 소리입니다.
4. **고민별 다듬기**: 들리는 고민을 누르면 알맞은 값을 조금 바꾸고, 무엇을 얼마나 바꿨는지 말로 보여 준 뒤 시험 연주합니다. `바꾼 패널 보기`는 그 패널로 가서 빛나게 하고(간단히 보기에 없는 패널이면 모두 보기로), `되돌리기`로 돌아갑니다. 여러 번 누르면 더 갑니다.

| 고민 | 바꾸는 값 |
|---|---|
| 먹먹하고 어두워요 / 쨍하고 귀가 아파요 | 차단 주파수 ×1.6 / ×0.65 (줄 뜯기는 줄 밝기 ±0.15), 고음 EQ ±2 dB |
| 누르고 소리가 늦게 나요 / 첫소리가 딱딱해요 | 볼륨 어택 ×0.4·필터 어택 ×0.5 / 어택 ×2.5(30ms 이상)·어택 소리 ×0.5 |
| 소리가 뭉개지고 길게 남아요 / 좁고 답답해요 | 릴리즈 ×0.6·잔향 ×0.7·잔향 길이 ×0.8·딜레이 ×0.6 / 잔향 +0.12·길이 ×1.3·폭 +0.2 |
| 밴드 소리에 묻혀요 | 중음 +3 dB 를 2 kHz 에, 컴프레서 +0.2 |
| 베이스·킥과 부딪혀요 | 저음 EQ −4 dB (베이스 음색은 −2) |
| 소리가 얇아요 | 오실레이터 1 겹치기 +2·퍼짐·코러스 (줄·샘플은 코러스·폭) |
| 밋밋하고 안 움직여요 | LFO 가 꺼져 있으면 필터를 0.25 Hz 로 천천히 흔들기, 아날로그 흔들림 +0.15 |

5. **모두** 보기에서 필터(밝기)·엔벨로프(시작과 끝)·잔향(공간)을 직접 바꾸고, `이펙트 끄고 듣기`로 견준 뒤 저장합니다.

## 음높이 맞추는 법

1. **기준음**: 함께 칠 피아노·오르간이 있으면 튜닝 화면의 마이크 튜너를 켜고 그 악기의 음(보통 A)을 길게 칩니다. 높이가 0.4초 넘게 고르게 이어지면 `이 소리에 기준음 맞추기`가 켜지고, 누르면 그 소리가 지금 음률에서 딱 맞게 들리는 기준음으로 바꿉니다(415~466 Hz 안). 악기가 없으면 440, 오케스트라와는 442.
2. **조옮김**: 노래 키에 맞춰 ± 반음. 손은 익숙한 자리로 치고 소리만 옮깁니다. 세트리스트에는 곡마다 저장됩니다.
3. **음률**: 보통은 12평균율. 한 조에 머무는 패드·오르간 곡이면 순정률 + 기준 조 = 곡의 조를 `평균율 ↔ 이 튜닝 번갈아 듣기`로 견줘 고릅니다.

## 무대에서 (연주 · 세트리스트)

- 곡 순서대로 음색을 고르고 조옮김을 맞춘 뒤 `지금 음색으로 곡 추가`. 곡마다 이름·조옮김·BPM(비우면 그대로)·메모를 고칠 수 있고, 음색은 그때의 사본이 담깁니다(나중에 내 음색을 고쳐도 세트리스트 소리는 그대로).
- 연주 화면을 열어 두면 `→`·`PageDown`·`]` 로 다음 곡, `←`·`PageUp`·`[` 로 이전 곡, 숫자 `1~9` 로 그 곡. 블루투스 페이지 넘김 페달은 보통 PageDown/PageUp 이나 화살표를 보내서 그대로 됩니다. MIDI 건반의 프로그램 체인지(1번 = 첫 곡)는 어느 화면에서나 곡을 바꿉니다.
- 곡을 넘기면 음색·조옮김·BPM(루퍼 박도 같이)이 한 번에 바뀝니다. 울리던 음은 끊지 않으니 필요하면 `모두 멈춤`.
- 연주 화면에 있는 동안은 화면 꺼짐 방지(Wake Lock)를 켭니다. 지원하지 않는 브라우저면 기기의 자동 잠금을 꺼 두세요.
- 블루투스 이어폰·스피커는 소리가 늦게 옵니다. 유선 이어폰이나 오디오 인터페이스를 쓰세요.
- 세트리스트·내 음색·튜닝은 이 브라우저에만 남습니다. 다른 기기로 옮기거나 백업하려면 `파일로 내보내기`.

## 음원 따라 만들기는 이렇게 합니다

고른 구간(최대 12초)을 재서 종류를 먼저 정합니다.

| 종류 | 언제 | ① 닮은 음색 만들기가 하는 일 |
|---|---|---|
| **한 음** | 악기 하나가 한 음을 낼 때 (전주의 패드 한 음, 끝 음, 악기 시연 영상) | 배음 128개의 세기를 재서 **파형을 직접 그리고**, 어택·서스테인·릴리즈, 첫소리 밝기(필터 엔벨로프), 비브라토·트레몰로, 숨소리(배음 사이 바닥), 늘어난 배음(피아노 줄 → FM), 첫소리 잡음(어택 소리), 좌우 폭, 꼬리의 잔향을 옮깁니다 |
| **화음·지속음** | 여러 음이 함께 울릴 때 | 값으로 본 가장 닮은 기본 음색 셋을 실제로 연주해 견주고, 가장 닮은 것에서 출발해 공간·폭·어택을 옮깁니다 |
| **여러 소리 섞임** | 밴드 전체가 나오는 곳 | 같은 방법으로 성격을 맞추고 **톤 균형**에 집중합니다. 악기 하나로 똑같이 만들 수는 없어서, 소리 그대로가 필요하면 ③·④ 를 쓰세요 |

만든 음색은 **같은 음·같은 길이로 미리 연주(OfflineAudioContext)해서 원음과 같은 자로 다시 잽니다.** 꼬리 크기·줄어드는 속도 차이로 잔향을 고치고, 옥타브 10띠의 톤 균형 차이를 **맞춤 EQ** 로 메웁니다. `더 비슷하게`는 차단 주파수·어택·디케이·숨소리·폭·잔향 등을 하나씩 위아래로 움직여 닮은 정도가 오르는 쪽만 받아들입니다.

**닮은 정도**는 톤 균형·배음·엔벨로프·밝기·폭·공간을 견준 점수입니다. 같은 엔진으로 만든 소리(기본 음색을 듣고 그 음색을 빼고 만들기)는 77~95% 가 나옵니다. 실제 녹음, 특히 여러 악기가 섞인 곡은 점수가 낮고 귀로 들어 판단해야 합니다.

### MIDI 와 함께 불러오기

음원 파일과 같은 곡의 MIDI(`.mid`)가 있으면 `MIDI 함께 불러오기 (선택)` 로 넣으세요. 멀티트랙 데모처럼 악기마다 음원과 MIDI 가 따로 있을 때 가장 좋습니다.

- **트랙 고르기**: 트랙 이름이 음원 파일 이름과 겹치는 정도, 음표가 있는 때와 음원에서 소리가 나는 때가 겹치는 정도로 맞는 트랙을 고릅니다. 틀리면 목록에서 바꾸세요.
- **구간 추천**: 다른 음과 겹치지 않고 오래 울리는 음을 골라 음 이름(`A2`, `C#5` …)을 붙입니다. 타악기처럼 음표가 짧아도 소리는 다음 음 직전까지 울리므로 구간을 그만큼 잡습니다. 한 음만 울리는 곳이 없으면 가장 긴 화음을 고릅니다.
- **같은 음으로 견주기**: 만든 음색을 구간 안의 MIDI 음 그대로(높이·시작·끝·세기) 연주해 원음과 잽니다. 0.25초 넘게 함께 울리는 음이 있으면 화음으로 보고 기본 음색에서 출발합니다. 앞 음의 꼬리만 걸친 음은 넣지 않습니다(새로 친 음처럼 첫소리를 내면 안 되니까).
- **음높이 바로잡기**: 한 음 구간에서 잰 높이가 MIDI 음과 이름은 같고 옥타브만 다르면 MIDI 옥타브로 바로잡습니다. 이름이 다르면(가상악기 샘플이 건반과 다른 음으로 울리는 경우) 들린 높이를 믿고, 비교 연주도 들린 높이로 옮깁니다.
- 템포가 중간에 바뀌는 MIDI(템포 맵)도 초가 맞고, 주법을 바꾸는 키스위치 음(거의 한 음씩 치는 트랙에서 함께 눌린 아주 낮은 음)은 빼고 견줍니다.

- **② 톤만 입히기**: 지금 음색은 그대로 두고 원음의 톤 균형(맞춤 EQ)·공간·폭만 입힙니다. 좋아하는 기본 음색을 그 곡 느낌으로 바꿀 때.
- **③ 구간을 샘플로**: 구간을 그대로 샘플러에 걸어 건반으로 칩니다 (루프 자동).
- **④ 앰비언트 패드로 늘리기**: Paulstretch(창마다 위상을 흩어 늘리기)로 4~16배 늘려 흐르는 패드를 만들고, 길게 크로스페이드한 루프로 겁니다. 곡의 화음 느낌이 그대로 남는 워십 패드가 됩니다.

## 실제 멀티트랙으로 만든 음색

큐버지(Studiocvrg)가 무료로 나눈 데모 멀티트랙 두 묶음(국악기 데모 · Arturia Pigments 데모, 악기별 음원 + MIDI)을 이 앱의 `음원 따라 만들기`와 같은 자로 재서 음색 19개를 만들었습니다. **음원·MIDI 는 비상업 용도만 허락되고 재배포·판매가 금지라서 저장소에 넣지 않았습니다.** 저장소에 있는 것은 재서 얻은 값(배음표·엔벨로프·잔향·맞춤 EQ 같은 음색 숫자)뿐입니다.

| 묶음 | 음색 |
|---|---|
| 국악기 (`국악기` 서랍) | 가야금 · 산조 가야금 · 해금 · 대금 · 징 · 꽹과리 · 장구 · 북 · 놋주발(싱잉볼), 현악 서랍의 약음 현(소르디노) |
| 신스 | 90s 폴리 키 · 몽환 피아노(건반), 리버스 패드 · 게이트 스웰(패드), 퓨처 플럭 · 물리 모델 플럭(줄·플럭), 하울 베이스(베이스), 라이저(상승) · 물결 쉬머(텍스처) |

만든 방법: ① 악기마다 MIDI 로 한 음 구간을 골라 배음·엔벨로프·비브라토·숨소리·잔향을 잼 → ② 그 값을 바탕으로 악기답게 손으로 짬(가야금·해금·대금·징·북·놋주발은 다시 합성한 실제 배음표, 북·장구는 음정 엔벨로프로 '둥', 꽹과리는 FM 금속음, 리버스 패드는 4분음표마다 톱니 LFO 로 부풀었다 끊기기, 게이트 스웰은 1.8초 부풀다 끊기기, 라이저는 음정·필터가 함께 올라감) → ③ 그 구간에 대 보며 맞춤 EQ·엔벨로프·잔향을 맞춤 → ④ 연주용으로 다듬음(잔향 0.7·폭 1.7·맞춤 EQ ±8dB 까지, 맨 아래 32Hz 띠는 올리지 않음, 베이스·북 종류만 +3dB 까지) → ⑤ 다른 음색과 같은 크기로 맞춤(가장 큰 0.4초 구간 −19dB, 볼륨으로 모자라면 맞춤 EQ 띠 전체를 함께 올림).

같은 스템에 대 본 닮은 정도(%, 들린 높이로 연주): 장구 85 · 징 82 · 가야금 81 · 90s 폴리 키 80 · 북 79 · 대금 78 · 라이저 78 · 하울 베이스 76 · 약음 현 74 · 해금 70 · 놋주발 70 · 게이트 스웰 70 · 꽹과리 67 · 물리 모델 플럭 67 · 산조 가야금 66 · 몽환 피아노 66 · 퓨처 플럭 61 · 리버스 패드 55 · 물결 쉬머 47. 만든 구간에 맞춘 값이라 그 구간에서 잰 점수이고, 같은 악기의 다른 음(두 번째 구간)은 대개 5~15점 낮습니다(놋주발은 음마다 배음 구조가 달라 24). 리버스 패드의 LFO 는 박이 아니라 소리를 켠 때부터 돌아서, 실제 곡에서는 4분음표 박과 어긋날 수 있습니다.

## 이펙트 설정과 시험

잔향·딜레이는 값만 바꾸는 게 아니라 **바로 들어 보고 숫자로 확인**할 수 있습니다.

| 하는 일 | 어디서 | 무엇을 알 수 있나 |
|---|---|---|
| 시험 연주 | 음색 만들기 맨 위 `들어 보기` | 건반 없이 한 음·화음·아르페지오·끊어 치기(잔향 꼬리 듣기). 베이스는 낮은 음, 모노 음색은 한 음씩 |
| A/B | `이펙트 끄고 듣기` | 저장된 음색은 그대로 두고 드라이브~잔향·EQ·폭을 잠깐 빼서 이펙트가 하는 일을 견줌 |
| 꼬리 재기 | `잔향 · 공간` 패널의 그림 | 5ms 짧은 소리를 이펙트 줄에 넣고, 같은 줄에서 딜레이·잔향만 뺀 소리를 빼서 젖은 소리만 잽니다. 꼬리 길이(RT60, 슈뢰더 적분), 시작 시간(프리딜레이+방 종류), 직접음 대비 크기, 좌우 넓이, 딜레이 반복 간격·좌우 번갈아. 값을 바꾸면 다시 잽니다 |
| 내 소리에 걸기 | 샘플러 `가공` → `지금 음색의 이펙트 입히기` | 녹음·불러온 소리에 지금 음색의 이펙트를 꼬리까지 구워 넣고, 원래대로 되돌리거나 스테레오 WAV 로 저장 |

잔향 종류는 같은 길이라도 첫 반사·밀도·밝기가 다릅니다: 룸(가까운 첫 반사가 빽빽), 홀(고르고 부드럽게, 예전 잔향과 같음), 교회(천천히 차오르고 어둡게), 플레이트(반사 없이 바로 빽빽하고 밝게), 스프링(일정한 간격의 띠잉), 앰비언트(천천히 부풀며 출렁임). 고역 감쇠는 꼬리가 갈수록 어두워지는 정도(벽이 소리를 먹는 정도)입니다.

## 소리 구조

```text
음 하나: 오실레이터 ×겹치기(아날로그 흔들림·위상 흩기) (+FM·노이즈) | 줄 뜯기 | 샘플
         ─ 필터 12/24dB (엔벨로프·LFO·세기) ─ 트레몰로 ─ 볼륨 엔벨로프
         + 어택 소리(해머·숨) + 옥타브 위 복사본 → 쉬머(잔향으로만)
악기:   음들 ─ 드라이브 ─ 로파이 ─ 페이저 ─ 코러스 ─┬─ 그대로 ──────────────┐
                                                  ├─ 딜레이(BPM 에 맞춤, 가운데·핑퐁·테이프) ──┤
                                                  └─ 프리딜레이 ─ 잔향(6종류) ────────────────┴─ EQ 3밴드 ─ 맞춤 EQ ─ 컴프 ─ 스테레오 폭 ─ 볼륨
스튜디오: 악기들 ─ 리미터 ─ 마스터 ─ 오실로스코프 ─ 스피커
```

- 줄 뜯기는 band2sheet `sound.py` 의 Karplus-Strong 을, 잔향 임펄스는 AirChoir `audio.js` 방식을, 따뜻한 파형 배음은 두 앱의 합성기를 옮겼습니다. 앱끼리 코드를 직접 불러오지는 않습니다.
- 모든 악기가 `freq(midi)` 하나로 음높이를 얻어서 튜닝을 바꾸면 신스·줄·샘플·루퍼 트랙이 다음 음부터 함께 바뀝니다.
- 같은 `Instrument` 를 `OfflineAudioContext` 에 만들면 '음색 굽기'·'음원 따라 만들기'의 비교 렌더·'꼬리 재기'·'이펙트 입히기'가 됩니다. 아날로그 흔들림도 시드가 있는 난수라 같은 음색은 늘 같은 소리로 렌더됩니다.
- 미리 연주는 한 번에 하나씩 차례로 돌립니다. 크롬에서 잔향이 있는 렌더 둘이 동시에 돌면 꼬리가 잘리거나 딜레이가 비는 일이 있어(꼬리 재기 검사에서 발견) 줄을 세웠습니다. 같은 잔향 임펄스는 한 번만 만들어 나눠 씁니다.

## 한계

- 여러 악기가 섞인 곡에서 악기 하나만 골라 내지는 않습니다(음원 분리 없음). 악기가 혼자 나오는 구간을 고르거나 ③·④ 를 쓰세요. band2sheet 의 음원 분리로 뽑은 악기 트랙을 불러오면 '한 음' 방식이 됩니다.
- 다시 합성한 파형은 잰 음높이의 배음 모양을 다른 음에도 그대로 씁니다(웨이브테이블 방식). 원음에서 멀리 떨어진 음은 실제 악기와 달라질 수 있습니다.
- MIDI 는 같은 곡의 같은 악기여야 쓸모가 있습니다. 트랙 자동 고르기·키스위치 거르기는 어림이라 틀릴 수 있고(트랙 목록에서 바꾸기), 박 앞에서 미리 울리는 소리(리버스 샘플)나 건반을 떼도 계속 울리는 소리는 MIDI 음 길이와 실제 소리 길이가 다릅니다.
- 샘플러는 한 소리를 건반 전체에 늘려 씁니다(멀티 샘플·벨로시티 레이어 없음).
