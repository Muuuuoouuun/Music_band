# 음색 공방 (Soundsmith)

브라우저에서 바로 소리가 나는 **가상악기 목업**입니다. 예배 중에는 큰 패드로 음색을 바꾸고, 실험실에서는 음색을 고르고 다듬고 파형까지 그리고, 녹음한 소리의 루프 지점을 잡고, 박에 맞춰 겹쳐 쌓고, 튜닝을 바꿔 볼 수 있습니다. 무엇을 왜 이렇게 만들었는지는 [음색 앱 조사](../../docs/SYNTH_APP_RESEARCH.md)의 1·3단계를 따릅니다.

화면 디자인은 시안 4개 중에서 고른 조합입니다: 전체 색과 질감은 **A(공방 패널: 어두운 바탕·금색)**, 예배 무대의 구조는 **C(무대 연주)**, 실험실은 **B(쓰임새로 고르고 한 문장으로 설명)** 위에 **D(소리 흐름 그림·배음 그리기·끄는 그래프)**를 얹었습니다.

## 실행하기

```bash
cd apps/soundsmith
npm start            # python3 -m http.server 8010
# Chrome·Edge·Safari 에서 http://localhost:8010 열기
```

패키지 설치가 필요 없습니다. 외부 라이브러리·워클릿 없이 브라우저 기본 Web Audio 노드만 씁니다. 글꼴은 Google Fonts 에서 받고, 못 받으면 시스템 글꼴로 바뀝니다. `소리 켜기`를 누르거나 건반을 처음 치면 소리가 켜집니다.

## 화면

| 화면 | 할 수 있는 것 |
|---|---|
| **예배 무대** `#stage` (첫 화면) | **세트 리스트**(곡마다 음색·조옮김, 곡을 누르면 함께 바뀜, `이전 곡`·`다음 곡 ▶`), **음색 패드 8개**(숫자 키 `1`–`8`, `패드 바꾸기`로 패드마다 음색 지정), **손가락으로 미는 판**(가로 밝기 × 세로 공간, 패드를 바꿔도 위치 유지, 화살표 키·슬라이더로도 조절), 큰 `패드 홀드`, 루퍼 한 줄(재생·녹음·트랙 진행 막대), 큰 건반. `세트 편집`에서 곡 추가·이름·음색·조옮김·빼기. 처음에는 저장소의 예배 음원 세 곡으로 채운 예시 세트가 들어 있습니다 |
| **실험실** `#lab` | 위: **어떤 자리에 쓸까요?**(찬양 인도 밑에 깔기·기도회·묵상·밴드 합주·찬송가 반주·솔로 멜로디)로 거른 음색 카드 14개 + 내 음색, 고른 음색을 한두 문장으로 풀어 쓴 **지금 소리**("따뜻한 패드예요. 1.4초에 걸쳐 천천히 커지고…"), **도우미 슬라이더 4개**(밝기·따뜻함·공간·움직임), `C 코드로 들어 보기`, 랜덤·변주·되돌리기, `내 음색으로 저장`, **`무대 패드에 올리기`**, **`루퍼로 보내기`**, JSON 내보내기·불러오기<br>아래 **자세히 조절**: 소리 재료(신스·줄 뜯기·샘플)와 **소리 흐름 그림**(오실레이터 1·2·FM → 섞기 → 필터 → 볼륨 → 이펙트 → 출력, LFO). 상자를 누르면 그 부분을 고칩니다. 오실레이터는 **배음 24개를 끌어 파형을 그리고**(dB 눈금, 화살표 키로도), 필터는 **곡선의 점을 끌어** 차단 주파수·레조넌스를, 엔벨로프는 **꼭짓점 A·D·S·R 을 끌어** 바꿉니다. 슬라이더로 정확한 값도 넣습니다 |
| **샘플러 · 루프 지점** `#sampler` | 오디오 파일·마이크 녹음·데모 소리·**지금 음색을 샘플로 굽기**. 불러오면 무음 자르기 → 음높이 찾기(YIN) → 루프 지점 찾기가 자동으로 됩니다. 파형 위에서 시작·끝·루프 표시를 끌고(0 지점에 붙이기), 이음새 그림과 '매끄러움 %'를 보며 크로스페이드를 조절합니다. 루프 방식은 한 번만·반복·왕복. 감지한 음과 cent 로 기준 음을 맞추고, **SFZ 악기(.sfz + .wav)를 zip 으로 내보내** sfizz·Sforzando 같은 무료 플레이어에서 엽니다 |
| **루퍼** `#looper` | 4트랙, 트랙마다 다른 음색. 녹음할 트랙(●)을 고르고 `녹음`을 누르면 한 마디를 센 뒤 시작하고, 켜 둔 채로 돌면 한 바퀴마다 겹쳐 쌓입니다. `실행 취소`는 마지막 바퀴만 지웁니다. BPM·박자(4/4, 3/4, 6/8)·마디 수·퀀타이즈(4분·8분·16분·8분 셋잇단)·메트로놈·뮤트·솔로·트랙 볼륨. 소리 대신 음표를 기억하므로 나중에 트랙 음색이나 튜닝을 바꿔도 따라갑니다. 처음에는 72 BPM C–G/B–Am7–Fadd9 예시 루프가 들어 있습니다 |
| **튜닝** `#tuning` | 기준음 A4(415·432·440·442·443 바로가기), 조옮김, 전체 미세 조정, 옥타브 늘이기(피아노식 스트레치), 음률 6가지(12평균율·순정률·피타고라스·1/4 쉼표 가온음률·베르크마이스터 III·발로티)와 기준 조, 음마다 cent 직접 조정(막대 끌기·숫자), 건반별 주파수 표, **평균율 ↔ 이 튜닝 번갈아 듣기**, 마이크 튜너, Scala(.scl) 불러오기·내보내기 |

아래 건반은 늘 붙어 있습니다. 화면 건반(여러 손가락, 위쪽을 누르면 여리게·아래쪽은 세게), 컴퓨터 키보드(`A W S E D F T G Y H U J K` = C4부터, `Z`/`X` 옥타브), Web MIDI 건반(서스테인 페달 CC64 포함), `홀드`(서스테인)를 씁니다. 건반 옆 표시줄에 누른 음의 실제 주파수와 평균율에서 벗어난 cent 가 나옵니다.

## 소리 구조

```text
음 하나: 오실레이터 ×겹치기 (+FM 변조기·노이즈) | 줄 뜯기 버퍼 | 샘플 ─ 필터(엔벨로프·LFO) ─ 트레몰로 ─ 볼륨 엔벨로프
악기:   음들 ─ 드라이브 ─ 코러스 ─┬─ 볼륨 ─ 스튜디오 버스 ─ 리미터 ─ 마스터 ─ 오실로스코프 ─ 스피커
                                 ├─ 딜레이(BPM 에 맞춤, 되먹임 저역통과)
                                 └─ 잔향(합성 홀 임펄스)
```

- 줄 뜯기는 band2sheet `sound.py` 의 Karplus-Strong(분수 지연 올패스)을, 잔향 임펄스는 AirChoir `audio.js` 방식을, 패드·따뜻한 파형 배음은 두 앱의 합성기를 옮겼습니다. 앱끼리 코드를 직접 불러오지는 않습니다.
- 모든 악기가 `freq(midi)` 하나로 음높이를 얻어서 튜닝을 바꾸면 신스·줄·샘플·루퍼 트랙이 다음 음부터 함께 바뀝니다.
- 루퍼 트랙마다 악기를 따로 만들고, 같은 `Instrument` 를 `OfflineAudioContext` 에 만들면 '음색 굽기'가 됩니다.

## 저장되는 것

- 이 브라우저에만: 내 음색(`soundsmith.presets.v1`), 마지막 음색(`soundsmith.patch.v1`), 튜닝(`soundsmith.tuning.v1`), 세트 리스트·무대 패드(`soundsmith.stage.v1`). 저장이 막힌 환경에서도 동작합니다.
- 샘플과 루퍼 녹음은 **페이지 메모리에만** 있습니다. 새로고침하면 사라지니 남길 샘플은 SFZ zip 으로 내보내세요.
- 서버 전송은 없습니다.

## 테스트

```bash
npm test                         # 단위 검사 40개 (Scala 왕복, 순정률 5/4, YIN, 루프·크로스페이드, 루퍼 겹쳐 녹음, ZIP)
npm start &                      # 다른 창에서
PLAYWRIGHT_MODULE=$(npm root -g)/playwright/index.js npm run check
```

브라우저 검사는 이미 설치된 Playwright·Chromium 을 씁니다(새로 받지 않음). 자동 검사는 소리가 나는지·숫자가 깨지지 않는지·주파수가 맞는지까지 확인하며, 실제로 듣기 좋은지는 사람이 들어 봐야 합니다.

## 한계 (목업)

- 샘플러는 한 소리를 건반 전체에 늘려 씁니다(멀티 샘플·벨로시티 레이어 없음). 원음에서 멀어질수록 빨라지거나 느려집니다.
- 루퍼는 음표 루프입니다. 마이크 소리를 그대로 쌓는 오디오 루프는 AirChoir 의 오브가 맡습니다.
- 탭이 뒤로 가면 브라우저가 타이머를 늦춰 루퍼 박이 흔들릴 수 있습니다.
- claude.ai 미리보기 화면에서는 마이크·MIDI 가 막혀 있어 파일·데모 소리·화면 건반만 씁니다.
- 플러그인(VST3·CLAP·AU)은 아직 없습니다. 같은 구조를 C++ 로 옮기는 계획은 조사 문서 5단계에 있습니다.
