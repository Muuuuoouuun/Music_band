# 음색 공방 (Soundsmith)

브라우저에서 바로 소리가 나는 **가상악기 목업**입니다. 예배 중에는 큰 패드로 음색을 바꾸고, 실험실에서는 음색을 고르고 다듬고 파형까지 그리고, 녹음한 소리의 루프 지점을 잡고, 박에 맞춰 겹쳐 쌓고, **톤(밝기 균형)을 귀나 레퍼런스에 맞춰** 다듬을 수 있습니다. 노드 스테이지처럼 **피아노·오르간·신스를 겹치거나 건반을 나누고**, 힙합 샘플러처럼 **소리를 잘라 패드에 올려 비트를 찍고**, 예배 흐름에 맞춰 **전환 효과음·드론·반주**를 낼 수 있습니다. 무엇을 왜 이렇게 만들었는지는 [음색 앱 조사](../../docs/SYNTH_APP_RESEARCH.md)의 1·3단계를 따릅니다.

화면 디자인은 시안 4개 중에서 고른 조합입니다: 전체 색과 질감, 그리고 **돌리는 노브**는 **A(공방 패널: 어두운 바탕·금색)**, 예배 무대의 구조는 **C(무대 연주)**, 실험실은 **B(쓰임새로 고르고 한 문장으로 설명)** 위에 **D(소리 흐름 그림·배음 그리기·끄는 그래프)**를 얹었습니다. 세 번째 탭은 **톤·음색 설정이 주된 방향**이라 톤 시안 3(귀로 톤 잡기)을 바탕에 두고 톤 시안 1(레퍼런스에 맞추기)과 톤 시안 2의 '자리 비우기'를 합쳤습니다.

탭은 네 개입니다: 예배 무대 · 실험실 · 톤 맞추기 · **샘플 패드**. **샘플러**는 소리 재료의 하나라서 실험실의 '샘플' 상자 안에, **루퍼**는 예배 무대의 루퍼 줄을 펼친 자리에, **튜닝**(음 높이)은 톤 맞추기 화면 위 한 줄로 접혀 들어갔습니다. 예전 주소 `#sampler`·`#looper`·`#tuning` 도 그 자리로 열립니다.

이번 확장(하이브리드·오르간·피아노·샘플 패드·전환·반주)은 **기능과 디자인을 나눠** 진행했습니다. 기능을 먼저 넣고, 디자인 캔버스의 시안 6개(H0 정보 구조 · H1 하이브리드 · H2 오르간·EP·로터리 · H3 샘플 패드 · H4 무대 전환·드론 · H5 반주 만들기)를 그대로 화면에 옮겼습니다. 머리글의 칩은 화면마다 바뀝니다(샘플 패드에서는 `조각 수 · BPM · 스윙`, 그 밖에는 튜닝과 BPM).

**노브 쓰는 법**: 위나 오른쪽으로 끌면 커지고 아래·왼쪽은 작아집니다(Shift 를 누르면 4배 정밀). 손가락으로 끌어도 화면이 스크롤되지 않습니다. 화살표·PageUp/PageDown·Home/End, 선택한 채 휠로도 돌리고, **두 번 누르면 고른 음색의 원래 값**으로 돌아갑니다. 가운데가 0인 값(미세 음정·조옮김·도우미)은 링이 12시에서 양쪽으로 찹니다.

## 실행하기

```bash
cd apps/soundsmith
npm start            # python3 -m http.server 8010
# Chrome·Edge·Safari 에서 http://localhost:8010 열기
```

패키지 설치가 필요 없습니다. 외부 라이브러리·워클릿 없이 브라우저 기본 Web Audio 노드만 씁니다. 글꼴은 Google Fonts 에서 받고, 못 받으면 시스템 글꼴로 바뀝니다. `소리 켜기`를 누르거나 건반을 처음 치면 소리가 켜집니다.

| **샘플 패드** `#pads` | 힙합 샘플러(MPC·SP-404) 방식, 시안 H3: **자르고 → 패드에 올리고 → 찍기**. 소리 재료는 `파일 열기`(앞 30초)·`마이크로 녹음`(15초까지)·`실험실의 지금 샘플`·`데모 비트`(직접 합성한 붐뱁 90 BPM — 저작권 걱정 없음). 파형에 조각 번호와 마디가 보이고, 자르기는 `소리 시작점 감지`(민감도)·`8칸`·`16칸`·`직접`(파형을 눌러 자를 자리 더하기, 번호를 끌어 옮기기, 두 번 눌러 지우기 — 0 지점에 붙음). **원래 빠르기**를 추정해 `믿음 높음·보통·낮음`으로 보여 주고(틀리면 고쳐 쓰거나 ×2·÷2), `맞출 BPM` 을 적고 `BPM 맞추기`를 누르면 음 높이는 그대로 길이만 바꿉니다(WSOLA)<br>4×4 패드(1–4 가 맨 아래, 건반 C4부터 16음, 컴퓨터 키 `A W S E …`)마다 **짐작한 이름**(킥·스네어·닫힌 햇·열린 햇·코드 스탭·베이스 음 — 직접 고쳐 쓸 수 있음)과 끊김 그룹 표. 고른 패드: 음높이·볼륨·필터·어택·릴리즈 노브, 한 번/누르는 동안, 끊김 그룹(A·B·C), 거꾸로, 조각·이름. **스텝 시퀀서**: 쓰는 패드만 줄로(패드를 누르면 그 줄이 생김), `1마디`·`2마디`(32칸), 칸을 누르면 켜고 끄고 누른 채 위아래로 끌면 세기, `지운 칸 되돌리기`, 스윙 50–75%(MPC 느낌), 재생 중 `녹음`으로 찍어 넣기, 지금 마디.칸 표시, `원래 순서대로`·`붐뱁 뼈대`·`모두 지우기`. BPM 은 루퍼와 같이 씁니다. **로파이**: 비트(4–16)·샘플레이트(8–44.1 kHz)·**바이닐 잡음**·**테이프 흔들림**을 따로, 바로가기(SP-1200 느낌·카세트·아주 거칠게·깨끗하게). `WAV로 내보내기`는 패턴 2바퀴를 굽습니다 |

## 소리 구조

```text
음 하나: 오실레이터 ×겹치기 (+FM·노이즈) | 줄 뜯기 | 오르간 드로바(+퍼커션·키 클릭) | 피아노 샘플 | 샘플
         ─ 필터(엔벨로프·LFO) ─ 트레몰로 ─ 볼륨 엔벨로프        (피치 엔벨로프는 모든 재료의 음 높이에)
악기:   음들 ─ 드라이브 ─ [비트·페이저] ─ 코러스 ─ [로터리·좌우 트레몰로·로파이]
        ─┬─ 톤 EQ ─ 볼륨 ─ 스튜디오 버스 ─ 리미터 ─ 마스터 ─ 오실로스코프 ─ 스피커
         ├─ 딜레이(BPM 에 맞춤, 되먹임 저역통과) ─┤
         ├─ 잔향(합성 홀 임펄스) ──────────────────┤
         └─ 시머(잔향을 한 옥타브 올려 다시 잔향에) ┘
        + 겹친 음색: 악기 안의 작은 악기 2개 (건반 범위·옥타브·세기)
톤 EQ:  로우컷(하이패스) ─ 깊은 저음(로우 셸프) ─ 저음·먹먹함·몸통·명료함(피킹, 대역 폭에 맞춘 Q) ─ 공기(하이 셸프)
```

- `[ ]` 안의 이펙트는 처음 켤 때 만들어 끼웁니다(`fx.js`). 로터리는 800 Hz 로 나눠 혼(고음)·드럼(저음)마다 도플러(흔들리는 지연)·음량·좌우를 돌리고, 느림 ↔ 빠름에서 혼은 금방, 드럼은 천천히 따라옵니다. 시머의 옥타브 올림은 지연 시간을 톱니 모양으로 줄이는 방식(Chris Wilson 의 Web Audio 예제와 같음)이라 워클릿이 필요 없습니다.
- 오르간은 드로바 9개를 16′ 기준 배음(1·3·2·4·6·8·10·12·16)으로 담은 파형 하나라 가볍습니다. 퍼커션은 실제 B3 처럼 다른 건반을 누르고 있지 않을 때만 울립니다.

- 줄 뜯기는 band2sheet `sound.py` 의 Karplus-Strong(분수 지연 올패스)을, 잔향 임펄스는 AirChoir `audio.js` 방식을, 패드·따뜻한 파형 배음은 두 앱의 합성기를 옮겼습니다. 앱끼리 코드를 직접 불러오지는 않습니다.
- 모든 악기가 `freq(midi)` 하나로 음높이를 얻어서 튜닝을 바꾸면 신스·줄·샘플·루퍼 트랙이 다음 음부터 함께 바뀝니다.
- 루퍼 트랙마다 악기를 따로 만들고, 같은 `Instrument` 를 `OfflineAudioContext` 에 만들면 '음색 굽기'가 됩니다.
- 톤은 음색(patch)의 일부(`tone`)라 내 음색·무대 패드·루퍼 트랙·SFZ 굽기에 함께 따라갑니다. 톤 그래프는 톤 EQ 를 뺀 소리를 한 번 재 두고, 노브를 돌릴 때는 다시 재지 않고 `tone.js` 의 필터 응답(Web Audio 바이쿼드와 같은 식)을 더해 그립니다. 엔진 필터 응답과 이 계산이 같은지는 `engine.check.mjs` 가 확인합니다.
- 레퍼런스 비교는 대역마다 '전체 소리 대비 dB'라 음량이 달라도 비교됩니다. 그래프에서 지금 소리는 노브를 돌린 만큼 움직이고, 레퍼런스 선은 전체 크기가 바뀐 만큼 함께 옮겨 두 선 사이 거리가 표의 '차이'와 같습니다.

## 저장되는 것

- 이 브라우저에만: 내 음색(`soundsmith.presets.v1`, 겹친 음색·나누기 포함), 마지막 음색(`soundsmith.patch.v1`, 톤 포함), 튜닝(`soundsmith.tuning.v1`), 세트 리스트·무대 패드(`soundsmith.stage.v1`), 톤 레퍼런스의 잰 숫자와 따라갈 정도(`soundsmith.tone.v1`). 저장이 막힌 환경에서도 동작합니다.
- 레퍼런스 음원 파일 자체는 저장하지 않습니다(잰 숫자만 남음). 다시 들으려면 다시 엽니다.
- 샘플, 루퍼 녹음, 샘플 패드(조각·패턴)는 **페이지 메모리에만** 있습니다. 샘플 패드 패턴은 WAV 로 내보내 남기세요.
- 피아노 샘플(약 6 MB)은 처음 피아노를 고를 때 받고, 페이지를 닫기 전까지 다시 받지 않습니다. 새로고침하면 사라지니 남길 샘플은 SFZ zip 으로 내보내세요.
- 서버 전송은 없습니다.

브라우저 검사는 이미 설치된 Playwright·Chromium 을 씁니다(새로 받지 않음). 자동 검사는 소리가 나는지·숫자가 깨지지 않는지·주파수가 맞는지까지 확인하며, 실제로 듣기 좋은지는 사람이 들어 봐야 합니다.

## 한계 (목업)

- 톤은 한 화음(패드·건반은 C 장화음)으로 잽니다. 음역이 다른 곡에서는 균형이 조금 달라질 수 있습니다.
- 음원 레퍼런스는 보컬·드럼까지 섞인 전체 믹스라 악기 하나와 똑같이 맞출 수는 없습니다(그래서 30–50% 권장). 곡에서 악기 하나만 떼어 비교하는 것은 band2sheet 의 악기 분리를 붙이면 가능합니다.
- 피아노는 단3도마다 하나씩, 세기 3층이라 아주 여리게 칠 때의 결은 원본보다 거칩니다. 페달 소리·줄 울림 샘플은 넣지 않았습니다.
- 오르간·로터리·EP·808 은 실제 악기 녹음이 아니라 합성이라 노드·해먼드의 소리와 똑같지는 않습니다(상표·샘플은 가져올 수 없음).
- BPM 추정은 데모 비트로 72·90·118·128 에서 맞지만, 싱코페이션이 많은 소리는 두 배·절반·3분의 2 로 틀릴 수 있어 고쳐 쓰게 했습니다. WSOLA 로 많이 늘이면(±30% 넘게) 드럼이 번집니다.
- 패드 이름 짐작은 새로 생긴 소리의 낮은음 비율·밝기·울림 길이만 보는 간단한 규칙이라, 여러 악기가 겹친 조각은 틀릴 수 있습니다(패드 이름을 고쳐 쓰면 됩니다).
- 반주 만들기는 루퍼 한 바퀴(8마디)까지입니다. 그보다 긴 곡은 절·후렴을 나눠 넣습니다.
- 남의 음반을 잘라 발표하려면 저작권자의 허락이 필요합니다(샘플 클리어런스). 데모 비트와 우리가 녹음한 소리는 자유롭게 써도 됩니다.
- 샘플러는 한 소리를 건반 전체에 늘려 씁니다(멀티 샘플·벨로시티 레이어 없음). 원음에서 멀어질수록 빨라지거나 느려집니다.
- 루퍼는 음표 루프입니다. 마이크 소리를 그대로 쌓는 오디오 루프는 AirChoir 의 오브가 맡습니다.
- 탭이 뒤로 가면 브라우저가 타이머를 늦춰 루퍼 박이 흔들릴 수 있습니다.
- claude.ai 미리보기 화면에서는 마이크·MIDI 가 막혀 있어 파일·데모 소리·화면 건반만 씁니다.
- 플러그인(VST3·CLAP·AU)은 아직 없습니다. 같은 구조를 C++ 로 옮기는 계획은 조사 문서 5단계에 있습니다.
