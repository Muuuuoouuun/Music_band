# ADR 0001 — 음색 공방 피아노: 유료 3종은 합성으로 흉내, 무료 1종은 로컬 샘플로

- 상태: 채택 (브랜치 `feat/soundsmith-pianos`, 아직 push·병합 안 함)
- 날짜: 2026-10-23
- 대상: `apps/soundsmith`

## 배경

인스타그램 릴 [`DdTSrolSO5V`](https://www.instagram.com/reel/DdTSrolSO5V/) (@studiocvrg, "나만 알고싶은 피아노 가상악기 3+1")에서 소개된 피아노를 음색 공방에 넣고 싶다는 요청.
릴 영상 화면은 보지 못했고(로그인 없이 읽히는 캡션만 확인), 캡션 설명은 다음과 같다.

| 악기 | 캡션 설명 | 가격 |
|---|---|---|
| The Grandeur | 깔끔하고 단정한 톤, 노브로 다듬기 | 유료 |
| Piano in Blue | 빈티지 재즈 피아노, 테이프 잡음, Vintage Mono | 유료 |
| Keyscape | 팝 중심, 폭넓은 장르 | 유료 |
| Woodland Piano | 무료, 따뜻하고 폭신한 소리, 숲 바람 앰비언스 | 무료 |

사용자 결정(음성 입력): **유료 3종은 앱 엔진으로 합성해서 만들고, 무료 1종은 가져온다.**

## 결정

1. **유료 3종은 합성 프리셋으로 '분위기만' 흉내 낸다.** 상표 이름을 그대로 쓰지 않고 `그랜듀어풍`·`블루 빈티지풍`·`키스케이프풍`으로 표기(오마주). 상용 샘플·IR·스크린샷은 쓰지 않는다. 고정 id: `clean-grand`, `blue-vintage`, `pop-keys`. 기존 id·순서는 건드리지 않고 목록 끝에 붙인다.
2. **`piano` 분류를 `CATEGORIES` 에 추가**한다(`건반` 바로 뒤). `RANDOM_KINDS`(랜덤 만들기)에는 넣지 않는다. 랜덤 피아노는 의미가 없다.
3. **합성 방식**(엔진 변경 없이 기존 노브만으로): 직접 그린 배음(`custom`, 위로 갈수록 줄어듦) + 같은 줄 두 가닥의 맥놀이(겹치기 2~3, 미세 음정) + 해머 딱 소리(짧게 줄어드는 FM) + 서스테인 0 의 엔벨로프(치면 줄어듦) + 건반 따라가기(높은 음일수록 밝게).
4. **빈티지의 'mono' 는 엔진의 `mono`(한 음씩 연주)로 만들지 않는다.** 플러그인의 Vintage Mono 는 *스테레오 폭을 좁힌* 소리이고, 이 앱의 `mono` 는 단성 연주라 피아노가 못 친다. 대신 코러스를 거의 빼서 좁게 만들고, 테이프 느낌은 약한 피치 흔들림(wow)·드라이브·가벼운 노이즈로 낸다. 테스트가 `mono === false` 를 확인한다.
5. **무료 1종(Woodland Piano)은 저장소에 넣지 않고 '로컬 전용 가져오기'로 한다.** 아래 라이선스 조사 참고.
6. **가져오기 경로는 범용 멀티샘플 로더**: `apps/soundsmith/local-samples/<세트>/` 에 파일을 놓고 `tools/make-sample-set.mjs` 로 `set.json` 을 만들면, 프리셋을 고를 때 `src/local-samples.js` 가 읽는다. 이 폴더는 gitignore(README 만 추적). 같은 방식으로 **살라만더 그랜드(CC BY 3.0)** 도 지원해 더 나은 대안으로 제공한다.
7. **엔진은 최소 변경**: 샘플 객체에 `zones` 가 있으면 누른 음에서 가장 가까운 녹음을 고르고(`pickZone`), 없으면 기존처럼 한 소리를 늘려 쓴다. 한 음에 벨로시티 층이 여럿이면 가운데 층 하나만 쓴다(메모리).
8. **기존 버그 수정(범위 밖이지만 필요)**: 루프 없는 샘플은 `start()` 전에 `stop()` 을 불러 크롬에서 예외가 났다(`InvalidStateError`). 멀티샘플이 루프 없이 쓰이므로 `start` 뒤로 옮겼다.

- 이번 작업에서는 **어떤 샘플도 내려받지 않았다**(Woodland 는 체크아웃 단계가 있고 2.4 GB, Salamander 는 394 MiB 이상).
- Woodland 는 "무료"이지만 *재배포 가능한 자유 라이선스가 아니라* 개인이 받아 쓰는 무료 배포다. 그래서 각자 내려받아 자기 컴퓨터에서만 쓰게 하고, 저장소·배포본에 포함하지 않는다.
- 살라만더를 쓰는 화면·배포물에는 `Piano samples by Alexander Holm (CC BY 3.0)` 표시가 필요하다. `set.json` 의 `credit` 이 선택할 때 안내로 뜬다.

## 결과

- 좋은 점: 상용 샘플 없이 같은 앱 안에서 쓸 수 있고, 라이선스 위험이 없다. 로컬 샘플 경로는 이후 다른 무료 샘플도 같은 방식으로 붙일 수 있다.
- 감수할 점: 합성이라 진짜 피아노와는 거리가 있다(배음이 모두 정수배라 줄의 비조화성이 없음). 로컬 샘플은 사용자가 직접 내려받아 놓아야 소리가 난다. 톤 탭은 로컬 샘플 소리를 재지 못한다(`app.sample` 이 없다고 봄).

## 확인하지 못한 것

- 합성 피아노가 **귀에 어떤지**(자동 검사는 음높이·크기·줄어듦만 봄). 릴 영상의 실제 소리와 비교하지 못함.
- Woodland Piano 압축 안에 일반 wav/flac 이 있는지(Kontakt 전용 `.ncw` 일 수 있음), 제작자의 정확한 사용 조건.
- 살라만더 파일 이름 규칙(`Ds1v8` 식 샤프 표기)은 FreePats/GitHub 문서로 추정했고 실제 파일로 확인하지 못함. 안 맞으면 `parseSampleName` 정규식을 조정.
- 로컬 샘플을 실제 피아노 파일로 불러 연주해 보지 못함(합성 사인 2개로 로더·멀티샘플 선택만 브라우저에서 확인).
