## 1. 분할 (구간별 누가 무엇을)

절 = a+b, 후렴 = c+b. 시각은 영상 기준입니다(못갖춘 음은 그보다 한 박쯤 앞).

## 2. 화성 (어떻게 쌓았나)

세 파트 모두 **멜로디와 같은 리듬**으로 움직입니다(호모포니). 가사를 따로 맞출 필요 없이 음만 다르게 부르면 됩니다.

- **윗화음**: 멜로디 위 3도가 기본이고, 코드 구성음이 4도 위에 있으면 그 음을 탑니다. 절 첫 마디는 F5 를 지속음으로 붙잡아 쉽고,
  후렴 첫 줄(멜로디 B♭ → D)은 D5 → F5 로 같이 올라갑니다.
- **아랫화음**: 멜로디 아래 3도(또는 코드음). 절 2마디는 B♭3 까지 내려가고, 후렴 끝(b)은 E4 – C4 로 C 코드를 받쳐 F 로 닫습니다.
- **못갖춘 음 (A–B♭–C)**: 매번 같은 모양 — 윗화음 **C–D–F**, 아랫화음 **F–G–A**. 절·후렴 들어갈 때마다 똑같이 연습하면 됩니다.
- **후렴 3마디 G7**: 윗화음 B♮(멜로디 F 위), 아랫화음 B♮(멜로디 D 아래). 이 곡에서 유일한 임시표라 연습 때 짚어 주세요.
- 원곡 코러스를 분석해 보니 대부분 **멜로디를 한 옥타브 위로 겹쳐** 부릅니다(코러스 음높이의 약 절반이 메인 +12반음).
  이 3성부 화성은 그 위에 새로 짠 편곡이고, 원곡처럼 옥타브 유니즌으로 부르고 싶은 구간은 High 대신 멜로디를 옥타브 위로 부르면 됩니다.

## 3. 어떻게 만들었나

1. `band2sheet run` 으로 Demucs 6스템 분리 → 보컬 스템을 Mel-RoFormer Karaoke 로 **메인 / 코러스** 분리.
2. 메인 보컬 CREPE 음높이를 8분음표 격자에 모으고, 4마디 프레이즈 템플릿을 곡 전체에 대조해 구조(a·b·c)와 시각을 찾음.
   같은 프레이즈가 나오는 4~6번을 겹쳐 다수결로 멜로디를 정함.
3. 반주 스템 크로마로 반 마디마다 코드를 정하고 등장 간 다수결 (예: 절 `F | B♭ F/C | F | B♭ Csus4`, 후렴 앞 `B♭ | Dm | G7 C | C B♭/C`).
4. 화음 음원은 악보의 High·Low 음을 목표로 메인 보컬을 **PSOLA** 로 옮겨 만듦 — 음원 속 화음 = 악보 음.

검증: 악보 멜로디(한 옥타브 아래)와 실제 메인 보컬을 8분음표 단위로 대조하면 **전체 75%** 일치, 후렴 앞(c)은 **84~92%**.
나머지는 대부분 인도자가 후렴 반복 끝에서 옥타브를 올리거나 바꿔 부른 애드리브(그 구간 b 는 33~50%)이고,
화음 음원은 이런 곳(악보 멜로디에서 1.5반음 넘게 벗어난 곳)에 화음을 붙이지 않습니다.
만든 화음 음원을 다시 pYIN 으로 재면 악보 목표음과 **윗화음 85% · 아랫화음 80%** 일치합니다(어긋남은 주로 짧은 음·자음 경계).

## 4. 한계

- 템포·마디 위치는 자동 박 추적입니다. 간주(2:28)와 다운 구간(3:43)에서 마디 첫 박이 한 박씩 밀리는데, 시각표에 반영했습니다.
- **다운 후렴(3:43–4:02)** 은 박이 늘어져 화음 음원에는 화음을 넣지 않았습니다(악보·분할표대로 부르면 됩니다).
- 새 화음 음원은 메인 보컬 목소리를 옮긴 것이라 실제 여러 사람 소리보다 기계적으로 들릴 수 있습니다. 음 확인·연습용입니다.
- 분리 음원은 팀 연습용입니다. 원곡 음원과 마찬가지로 외부에 배포하지 마세요.

## 다시 만들기

```bash
cd apps/band2sheet && .venv/bin/pip install -e ".[ml,detail]" onnxruntime   # 분리 엔진
.venv/bin/band2sheet run <원곡.mp3> -o /tmp/fia                              # 스템
# 보컬 스템 -> 메인/코러스 (band2sheet.separate.run_separator, KARAOKE 모델)
cd ../../arrangements/friend-in-jesus
python build.py                                                              # 악보·MIDI
python render_audio.py --stems /tmp/fia/stems --lead lead.wav --chorus chorus.wav
```
