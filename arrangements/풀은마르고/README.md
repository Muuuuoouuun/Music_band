# 풀은 마르고 — 3성부 화음

- `풀은마르고-화음.pdf` — 인쇄용 악보 (높은 화음 / 멜로디 / 낮은 화음)
- `풀은마르고-화음.musicxml` — MuseScore 등에서 열어 고치거나 들어볼 수 있는 파일
- `build.py` — 위 MusicXML을 만드는 스크립트. 음을 고치면 `python3 build.py`로 다시 만든다.

## 기준
- 원본은 G장조로 인쇄돼 있지만 손으로 적은 코드가 F장조라서 **F장조(원본보다 장2도 아래)**로 옮겨 적음.
- 파란 표시 = 높은 화음, 주황 표시 = 낮은 화음. 원본에 표시가 있는 구간에서만 그 성부가 부름.

| 구간 | 높은 화음 | 낮은 화음 |
|---|---|---|
| A (1번째) | ○ | ○ |
| A (반복) 앞 4마디 | 제창 | 제창 |
| A (반복) 뒤 4마디 | – | ○ |
| A' 주의 말씀을 믿는 자 / 그의 구원을 얻으리 | ○ | ○ |
| A' 주의 말씀을 행하는 자 | – | ○ |
| A' 그의 능력을 보게 되리라 | ○ | ○ |
| B 1~3번째 | ○ | – |
| B 4번째 (마지막, 끝날 때 rit.) | ○ | ○ |

## 확인이 필요한 곳
사진에서 음을 읽은 것이라 아래는 원본과 한 번 맞춰 볼 것.
- A' "보게 되리라"의 "되" 음 (A로 읽음, B♭일 수도 있음)
- B 마지막 줄 끝 "영원해"의 리듬
