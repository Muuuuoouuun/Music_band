## 2. 라이브 음원에서 확인한 것

보컬만 따로 떼어(Demucs) 마디마다 음 높이를 읽고 악보 멜로디와 맞춰 봤습니다.

- **순서·전조·템포**: 위 표 그대로. 4:52 부근에서 B → C# 전조.
- **2절 "오셔서 다스리소서"**: 1절("주의 말씀 이루시리")은 악보의 **아래 음**(D#–D#–B / E–D#–C#–B)을, 2절은 **위 음**(F#–F#–F# / G#–B–A#–B)을 리드가 부릅니다. 악보의 두 음은 화음이 아니라 1·2절 멜로디였습니다.
  → 2절에서는 **멜로디 파트가 위 음, 아랫화음 파트가 아래 음**으로 바꿔 부릅니다(악보에 표시, 연습 음원도 그렇게 만듦).
- **싱어 화음**: 영상에서는 리드 소리가 커서 싱어 화음이 대부분 묻힙니다. 분명하게 잡힌 곳은 C' 후렴의 긴 음 "다"·"여"에서 나는 **E#5**(코드 C#/E#의 3음)뿐이라 그 두 음을 반영했습니다. 나머지 화음은 악보와 코드를 기준으로 만든 편곡입니다.

## 3. 화성 (어떻게 쌓았나)

세 파트 모두 **멜로디와 같은 리듬·같은 가사**로 움직입니다(호모포니).

- **윗화음**: 멜로디 위 3도가 기본. 후렴(B)에서는 B4를 길게 붙잡는 지속음이 많고, "거룩"·"곧 전능"·"나라 임하" 같은 올라가는 자리에서만 D#5–E5까지 움직입니다.
- **아랫화음**: 멜로디 아래 3도(또는 코드음). E 코드에서 멜로디가 F#일 때는 D#로 받아 Emaj7 색을 냅니다.
- **"주의 말씀 이루시리"(A' 14–16마디)**: 1절은 아랫화음이 2절 멜로디 줄(위 음)을, 2절은 서로 바꿔서 — 어느 쪽이든 두 줄이 함께 울리고 윗화음은 그 위(B4 → D#5).
- **B7/D# 마디("을 / 때")**: 윗화음이 A♮(B7의 7음). 이 곡에서 유일한 임시표라 연습 때 짚어 주세요.
- **브릿지(C)**: 멜로디가 B4에 머무는 낭송형이라 화음은 넓게 고정 — 윗화음 D#5(→ E 코드에서 E5), 아랫화음 F#4 → G#4. 마지막 "왕"은 악보 괄호 화음 그대로 A#4 + C#5 + F#4.
- **C' (C# 전조)**: B 후렴 화음을 온음 올리고, "다"·"여"만 라이브대로 E#5.

## 4. 원곡 악보와 다르게 적은 곳

- 코드 `C#/F`는 `C#/E#`로 표기(같은 음).
- 브릿지 마지막 회차 코드 `(last time)`는 악보 위 작은 글씨로 적었습니다.
- 전주(I)는 원곡 악보에 없어서 악보·연습 음원에 넣지 않았습니다.
